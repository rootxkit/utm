# Decision records

One file per decision, numbered and named: `001-qgc-forwarding.md`.

Each record states the context, the options considered, the decision, and the
evidence it rests on. Records are append-only — a decision that is later
reversed gets a new record that supersedes the old one, and the old one stays.

The open decisions waiting to be recorded are listed in `../ARCHITECTURE.md` §8.
